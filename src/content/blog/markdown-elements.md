## 列表

无序列表

- 在行首使用 `+`、`-` 或 `*` 创建列表
- 缩进两个空格即可创建子列表：
  - 更换列表标记会开始一个新列表：
    - 第一项示例内容
    - 第二项示例内容
    - 第三项示例内容
- 就是这么简单！

有序列表

1. 第一项内容

4. 可以使用连续的编号……
5. ……也可以全部使用 `1.`，编号会自动生成。

57. 示例一

### Expressive Code 示例

添加标题

```js title="file.js"
console.log("标题示例");
```

Bash 终端

```bash
echo "基础终端示例"
```

高亮指定代码行

```js title="line-markers.js" del={2} ins={3-4} {6}
function demo() {
	console.log("这一行被标记为删除");
	// 这一行和下一行被标记为新增
	console.log("这是第二行新增内容");

	return "这一行使用默认的中性标记";
}
```

[Expressive Code](https://expressive-code.com/) 还支持更多功能，并提供丰富的[自定义配置](https://expressive-code.com/reference/configuration/)。

## 表格

| 选项 | 说明                                                               |
| ------ | ------------------------------------------------------------------------- |
| data   | 数据文件的路径，用于向模板传入数据。 |
| engine | 用于处理模板的引擎，默认为 Handlebars。    |
| ext    | 生成文件所使用的扩展名。                                      |
